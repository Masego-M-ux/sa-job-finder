# SA Job Finder

## Project Overview

SA Job Finder is a simple website designed to help people in South Africa find entry-level job opportunities in one place.

## Problem

Youth unemployment is a major socio-economic challenge in South Africa. Many young people struggle to find entry-level jobs, internships and learnerships.

## Solution

SA Job Finder provides a simple platform that displays different entry-level opportunities and makes them easier to find.

## Technologies Used

* HTML
* CSS
* JavaScript
* GitHub
* AWS S3

## AWS Deployment

The website was deployed as a static website using Amazon S3.

## Project Goal

The goal of SA Job Finder is to provide a simple starting point for people looking for employment opportunities in South Africa.
